# Функциональные требования

Источник: З — запрос пользователя, Н — норма/стандарт, П — лучшая практика (см. [RESEARCH.md](RESEARCH.md)).
Роли: РМ — риск-менеджер, ВР — владелец риска, Н — наблюдатель.
Статус в прототипе: ✅ реализовано, ◐ частично, ⛔ только в целевой системе. Где посмотреть — страница приложения.
