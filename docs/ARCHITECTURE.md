# Архитектура

## ADR-1. Форма приложения — Streamlit + SQLite
**Контекст.** Нужен реестр с расчётами, загрузкой Word/Excel, тепловой картой и историей по неделям; показ по ссылке; пользователь задал Streamlit.
**Решение.** Streamlit (Python 3.12) + Plotly для карты и графиков, SQLite для состояния, python-docx/openpyxl для импорта.
**Альтернативы.** Одностраничник HTML — нет удобного разбора docx/xlsx и сервера для ИИ-ключа; FastAPI + React + PostgreSQL — правильно для рабочей системы, но в разы дольше.
**Последствия.** Масштаб — десятки одновременных пользователей; в Streamlit Community Cloud файл SQLite сбрасывается при перезапуске (для постоянного хранения — внешняя СУБД, интерфейс `core/db.py` это допускает); рассылки по расписанию — вне Streamlit.

## ADR-2. Оценка как журнал, а не поле
Каждая оценка — отдельная запись `assessment` с датой. Текущее положение = последняя оценка; положение на неделю = последняя оценка на конец недели (перенос вперёд). Так динамика по неделям считается из одних данных, импорт истории и переоценка работают одинаково.

## ADR-3. ИИ — подсказка, а не источник истины
Claude API (`claude-opus-5-5`, structured output по JSON-схеме, effort `low`, server-side fallback при отказе). Ключ — только из `ANTHROPIC_API_KEY` / `st.secrets`. Предложения помечаются источником «ИИ» и попадают в реестр только после подтверждения человеком.

## Модель данных (SQLite)
```
risk(id PK, code UNIQUE, title, description, category, owner, status, strategy,
     response_plan, due_date, trigger, target_p, target_i, source, created_at, updated_at, closed_at)
assessment(id PK, risk_id FK→risk, assessed_on DATE, probability 1..5, impact 1..5,
           comment, author, source[manual|import|ai|demo], created_at)
audit(id PK, ts, actor, role, action, risk_id, details)
setting(key PK, value JSON)        -- пороги уровней, шкалы, флаг демо
```

## Сквозные вопросы
- **Роли** — демо-выбор в боковой панели, явно помечен «не является защитой».
- **Даты** — локальная дата сервера; неделя — ISO (пн–вс), подпись «Нед 45 · 03.11».
- **Конкурентный доступ** — одна БД на процесс, `threading.Lock` на инициализацию и демо-наполнение, `check_same_thread=False`, WAL.
- **Секреты** — только `ANTHROPIC_API_KEY` (env или `st.secrets`), в репозиторий не попадают.
