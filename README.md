# Карта рисков — реестр и тепловая карта рисков (Streamlit)

Реестр рисков проекта с тепловой картой «вероятность × влияние», владельцами и динамикой по неделям.
Риски загружаются из **Word** и **Excel**, оцениваются вручную или с ИИ-подсказкой (Claude) и сразу появляются на карте.

## Что умеет
- **Импорт Word / Excel / CSV.** Excel — таблица на любом листе, шапка может быть не в первой строке, строки-разделы
  («1. Проектирование…») становятся категорией. Word — таблица или текст: пункты списка «Название: описание» в разделах
  про риски («Ключевые риски», «Нестыковки», «Подводные камни»), заголовки, «Риск 1. …», жирные строки. Несколько
  вариантов разбора — на выбор, колонки сопоставляются автоматически и правятся вручную, неразобранные колонки
  дописываются в описание.
- **Оценки из файла** — числом 1–5, словами («высокая», «очень низкое»), процентом вероятности. Если в файле только
  «Уровень риска», риск условно ставится на диагональ карты с пометкой «уточните».
- **ИИ-подсказка** (нужен ключ `ANTHROPIC_API_KEY`): предлагает В, Вл и категорию с обоснованием для неоценённых рисков;
  может извлечь риски из неструктурированного текста. Без подтверждения человеком ничего не сохраняется.
- **Тепловая карта 5×5** на любую неделю, стрелки движения с прошлой недели или с выбранной, клик по точке/ячейке.
- **Динамика по неделям:** число рисков по уровням, суммарный балл, лента «риск × неделя», лидеры роста и снижения.
- **Владельцы:** нагрузка, уровни, просроченные меры, давно не пересматривавшиеся риски.
- **Карточка риска:** переоценка с комментарием (история, а не перезапись), траектория на карте, целевое положение, меры.
- **Обзор «требует внимания»:** критические, выросшие за неделю, просроченные меры, без владельца, без оценки.
- **Журнал изменений**, **настраиваемые пороги уровней**, **выгрузка в Excel** (реестр, история, динамика, карта), шаблоны Word/Excel.
- Роли (демо-выбор): риск-менеджер, владелец риска, наблюдатель.

## Запуск
```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Windows; на Linux/macOS: .venv/bin/pip
streamlit run app.py
```
При первом запуске создаётся демо-реестр (условный проект «Внедрение ERP-системы», 20 рисков, 12 недель истории).
Очистить его можно на странице «Методика и настройки» или галочкой при импорте.

ИИ-подсказка: задайте переменную окружения `ANTHROPIC_API_KEY` или `.streamlit/secrets.toml`:
```toml
ANTHROPIC_API_KEY = "…"
```
Используется модель `claude-opus-5-5` (structured output, при отказе модели — автоматический server-side fallback).

## Тесты
```bash
pip install pytest
pytest            # правила, импорт, БД, отрисовка всех страниц под всеми ролями (AppTest)
```

## Публикация в Streamlit Community Cloud
1. Репозиторий на GitHub → share.streamlit.io → **New app** → `app.py`.
2. **Advanced settings → Python 3.12**; в Secrets — `ANTHROPIC_API_KEY`, если нужна ИИ-подсказка.
3. Данные хранятся в SQLite внутри контейнера и **сбрасываются при перезапуске** приложения — выгружайте реестр в Excel
   или подключите внешнюю СУБД (см. `docs/ARCHITECTURE.md`). Приложение засыпает после простоя — откройте ссылку заранее перед показом.

## Методика и источники
Процесс — ГОСТ Р ИСО 31000-2019; матрица «последствия / вероятность» — один из методов ГОСТ Р 58771-2019.
Шкалы и пороги — типовые (допущение), настраиваются. Подробно: [docs/RESEARCH.md](docs/RESEARCH.md),
требования и покрытие: [docs/FT.md](docs/FT.md), архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Ограничения
- Выбор роли — демонстрационный, это **не защита** доступа (в целевой системе — SSO и серверные права).
- Уведомления владельцам по почте/в мессенджер не реализованы: нужен почтовый сервер и планировщик. Сигналы — на «Обзоре».
- Матрица рисков — порядковая шкала: балл 12 не «вдвое хуже» 6. Это инструмент приоритизации, а не количественной оценки.
- Оценка, восстановленная по одному «уровню риска», условна — уточните В и Вл.
